# Governance and support

Agent Reliability Harness is currently maintained by Shuo Xu. Technical
decisions are discussed through public GitHub issues and pull requests. The
maintainer is responsible for merging changes, publishing releases, and applying
the security policy.

Bug reports, feature requests, documentation corrections, and reproducibility
reports are welcome through the public issue tracker. Support is provided on a
best-effort basis; there is no response-time or production-availability service
level agreement. Security-sensitive reports should follow `SECURITY.md` instead
of being posted publicly.

Changes that affect schemas, scoring semantics, fault truth, or statistical
interpretation require tests and an explanation of compatibility impact.
Releases use semantic versioning where practical, are tagged in Git, recorded in
`CHANGELOG.md`, tested in continuous integration, and archived through Zenodo.

If the contributor community grows, maintainership and decision rights will be
expanded based on sustained, constructive contributions and documented in this
file.
