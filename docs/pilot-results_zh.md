# 真实模型探索性工程验证

本文档记录首次公开发布前完成的工程验证，不构成模型能力的确证性比较。

## 范围

- 测试两个独立的OpenAI兼容供应商：MiniMax M3与DeepSeek V4。
- 每家供应商的主冒烟矩阵包含36个episode，覆盖6项文件任务、2种脚手架和3种执行条件。
- 另以确定性夹具完成864单元彩排，贯通计划、断点续跑、证据链、manifest、分析和验收流程，不据此提出模型能力结论。

## 工程结果

- MiniMax M3：36个主episode，28个达到核验终态；105次模型调用，共计47,517 Token；2个episode发生传输或解析错误。
- DeepSeek V4 Flash：36个主episode，27个达到核验终态；64次模型调用，共计64,671 Token；1个episode发生解析错误。
- DeepSeek V4 Pro另完成1个连接episode。

早期连接尝试暴露了供应商特有的推理包装、不完整JSON响应和输出预算截断。适配器与回归测试随后得到修正，同时确保API密钥不进入运行记录。

## 解释边界

任务集较小，探索期间调整过输出预算，而且数据采集前未完成预注册。因此上述计数不得用于供应商排名或总体效应估计。确证性研究必须先冻结模型标识、提示词、预算、排除规则和分析规则，再重新采集平衡矩阵。
